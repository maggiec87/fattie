# Fattie

简短说明：这是一个基于 HTML 的静态项目（网页）。

## 简介

此仓库包含一个简单的静态网站或页面，使用纯 HTML（可能包含 CSS/JS）来呈现内容。适合作为小型演示、模板或前端练习项目。

## 功能

- 基本的页面结构（HTML）
- 易于扩展为包含样式（CSS）和交互（JavaScript）
- 轻量、易于部署

## 使用方法

1. 克隆仓库：
   git clone https://github.com/maggiec87/fattie.git

2. 在浏览器中打开项目根目录中的 `index.html`（或其它 HTML 文件）即可预览页面。

## 本地开发

- 直接编辑 HTML/CSS/JS 文件并在浏览器中刷新查看效果。
- 推荐使用简易静态服务器以获得更好体验，例如：
  - npm: `npx http-server` 或 `npx live-server`
  - Python: `python -m http.server 8000`

## 部署建议

- 可直接将静态文件托管到 GitHub Pages、Netlify、Vercel 等静态站点服务。
- 若使用 GitHub Pages：在仓库设置中启用 Pages，并将发布分支设置为 `main` 或 `gh-pages`。

# 轻记 · 减脂日志（单文件 HTML 应用）

这是一个单文件静态网页应用（index.html），用于本地记录减脂相关的数据：体重、体脂、睡眠、运动、饮食、照片与目标。README 的重点是介绍这个 HTML 文件里包含的功能与如何使用它 — 而不是仓库管理细节。

## 核心特色

- 单文件部署：所有 CSS、JS、图标和 Web App Manifest 都内联在 `index.html` 中，无需外部资源。可直接把 `index.html` 放在任何静态托管或本地打开。
- 本地优先：首选使用 IndexedDB 存储（days / photos / meta）；在受限环境或不可用时回退到 localStorage 并提示用户。
- PWA 友好：页面内动态生成 manifest，支持安装为 Web App（独立窗口）并有主题色与图标。
- 离线可用：应用以本地存储为主，常态下可离线使用（浏览器允许时）。
- 图片支持：可以添加/查看/导出照片；会估算 dataURL 大小并在导出时提示。
- 导入/导出：支持 JSON 导入/导出以备份或在设备间迁移数据。

## 文件说明

- `index.html` — 单文件应用的全部代码（UI、样式、逻辑、图标、manifest 均在此文件内）。打开此文件即可使用应用。
- （如果你在本地看到其他文件，核心运行只需 `index.html`。）

## 快速开始（在本地）

1. 克隆或下载仓库，或只下载 `index.html`。
2. 直接在浏览器中打开 `index.html`：
   - 双击文件或用浏览器的“打开文件”功能。
   - 注意：某些浏览器在 `file://` 协议下可能限制 IndexedDB 或其他特性；提示会在界面中说明。
3. 建议使用本地静态服务器以获得更稳定的功能（推荐）：
   - Node (npm): `npx http-server` 或 `npx live-server`
   - Python 3: `python -m http.server 8000`
   然后在浏览器访问 `http://localhost:8000/index.html`。

## 使用要点

- 首次打开时，应用会尝试初始化本地数据库（IndexedDB）。如果失败，界面会显示原因并使用备用存储。
- 添加记录：在“今日/记录/趋势/我的”等页面里，可以填写体重、体脂、睡眠时间、运动、饮食等条目。
- 照片：可以通过相机或文件选择器上传照片（注意浏览器对 file:// 的限制）。
- 导出/备份：在“我的”或导出卡中导出为 JSON 文件以备份。导入功能可将 JSON 恢复到本地存储。
- PWA 与安装：浏览器允许时可将应用安装为独立 Web App（页面内已生成 manifest），体验更接近原生应用。

## 存储与权限提示

- 优先使用 IndexedDB；在受限环境（无痕模式、iframe 沙箱、file:// 等）下会降级到 localStorage，并且界面会给出诊断信息与警告。
- 图片以 dataURL 形式保存到本地（会占用浏览器配额），应用会估算并显示图片大小；大量大图可能触发配额限制。
- 如果出现“数据库不可用/配额不足/无痕模式”等提示，请在常规（非隐身）浏览器窗口或通过 http(s) 服务访问页面。

## 部署建议

- 直接把 `index.html` 放到任何静态托管服务：GitHub Pages、Netlify、Vercel 等。
- 若使用 GitHub Pages：将 `index.html` 放在默认分支根目录或 `gh-pages` 分支，启用 Pages 即可。

## 本地开发与调试

- 你可以在 `index.html` 内直接修改样式或脚本，保存后刷新浏览器查看效果。
- 推荐在浏览器控制台查看日志和 IndexedDB（Application/Storage 面板）以诊断存储问题。

## 常见问题

- Q: 打开后提示“本地数据库不可用”。
  A: 检查是否在 file:// 协议或无痕窗口中，建议运行本地静态服务器或在普通窗口打开。

- Q: 照片太大导致保存失败/配额不足。
  A: 使用较小分辨率的照片或在导出后清理不需要的大文件；应用会在导出时显示估算大小。
